GitHub Actions: Pins & Filter

Faster loading

GitHub sends only the first page of the workflow list. With access to github.com the extension fetches the rest in one go. Without it, it falls back to clicking GitHub's own "Show more workflows" button, one page at a time. Your favorites work either way.

Where pins are stored

On: pins travel with your browser profile through Firefox Sync or Chrome Sync. Off: pins stay on this machine. Switching moves the pins you already have.
