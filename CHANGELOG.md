# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project uses [semantic versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Favorites are drawn from a cached name list before the workflow list arrives, so they appear
  immediately instead of after the network settles.
- Automatic removals are recoverable. The options page lists them under **Removed automatically**
  with a **Restore** button.
- An options-page button to grant access to github.com, for Firefox, where host permissions are
  optional and cannot be granted from a README.
- Store assets at the sizes the Chrome Web Store requires, generated by `npm run screenshot`.
- `npm run verify:sidebar`: 22 checks against a real browser, covering the DOM behaviour unit tests
  cannot reach.
- 16 and 32 pixel icons, used by Chrome in the toolbar and on Windows.

### Fixed

- The sidebar stayed bare until a full page reload when Actions was reached by clicking the tab.
  The content script matched only the Actions URL, and GitHub navigates with Turbo.
- The filter searched only the ten workflows GitHub server-renders. Every page is now fetched, all
  at once rather than one per round trip.
- The filter box and favorites appeared as a full-width banner on workflow run pages, which have no
  workflow sidebar.
- Group headers disappeared shortly after the sidebar drew.
- A tab's own storage write could clear its favorites a moment after they were added.
- A group rolled up on one repository hid every row on a repository with no header to expand it,
  leaving an empty sidebar with no way back.
- The star no longer sits on top of GitHub's own row icons.

### Changed

- `https://github.com/*` moved from a required host permission to an optional one. It is not needed
  in Chrome, and Firefox treats it as optional regardless.
- Favorites are mirrored to local storage as well as sync, so a sync area that accepts a write and
  reads back empty cannot hide them.
